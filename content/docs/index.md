`grit` is a Git client with a small, modern command line. It works on any Git repository and talks to any Git remote, but its commands are its own: one obvious way to do the common thing, plain-language output, and `--json` on every command. If you're new, start with the [tutorial](tutorial/).

See [Install](install/) for download options, [Global options](global-options/) for flags shared by every command, and [Scripting with grit](scripting/) for `--json` and `--filter`.

## Building on the library

Everything `grit` does is built on `grit-lib`, a Git library for Rust. Start with the [library guide](library/) or browse the [grit-lib API documentation](https://docs.rs/grit-lib).
