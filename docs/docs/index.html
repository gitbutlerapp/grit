Docs

How to use grit, a simple Git client built on grit-lib. Start with the tutorial, then look up any command or open the library guide.

Grit is two things:

  • grit — a Git client with a small, modern command line. It works on any Git repository and talks to any Git remote, but its commands are its own: one obvious way to do the common thing, plain-language output, and --json on every command.
  • grit-lib — a fast, linkable Git library for Rust. Everything the CLI does goes through the library; you can embed the same engine in your own tools.

CLI vs library

Use grit when you want a day-to-day Git client from the terminal or in scripts (--json / --filter). Use grit-lib when you need programmatic access — opening repositories, reading objects and refs, diffing, revwalking, fetch/push, and the rest of Git's core — inside a Rust binary or service.

On-disk formats and the wire protocol stay compatible with Git; the CLI's argv and messages are deliberately not a Git mirror.

See Install for download options, Global options for flags shared by every command, Scripting with grit for --json and --filter, and the Agent guide for automation-focused details.

Commands

Getting started

grit initCreate a new, empty repository.
grit cloneCopy a remote repository into a new directory.
grit statusShow where you are and what's changed. This is what plain grit runs.
grit configRead, set, list or remove configuration values.

Making changes

grit addStage changes. With no paths, stages everything.
grit commitStage every change and record a new commit.
grit diffShow uncommitted changes, or the change a commit introduced.

History

grit logShow recent commits, newest first, a page at a time.
grit shortlogList the commits on this branch that aren't on the target branch yet.
grit showShow a commit, tag or branch, and a summary of what it changed.

Branches and tags

grit branchList branches, or create or delete one.
grit switchSwitch to another branch, or create one and switch to it.
grit mergeMerge another branch into the current one.
grit pickCopy a single commit onto the current branch.
grit tagList tags, or create or delete one. A new tag points at the current commit.

Remotes

grit remoteList remotes, or add one.
grit fetchDownload new commits, branches and tags from a remote.
grit pullFetch from the remote and bring the current branch up to date.
grit pushPublish the current branch, or your tags, to a remote.
grit authSign in to GitHub so HTTPS pushes and fetches just work.

Maintenance

grit updateUpdate grit to the latest release.
grit skillPrint an agent skill that explains how to use grit.
grit completionsGenerate shell completion scripts for bash, zsh, and fish.

Plumbing

grit upload-packServe a fetch or clone of a repository over stdin and stdout.
grit receive-packAccept a push to a repository over stdin and stdout.
grit managerA credential helper that stores passwords and tokens in the Windows Credential Manager.
