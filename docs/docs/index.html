Commands

Getting started

grit initCreate a new, empty repository.grit cloneCopy a remote repository into a new directory.grit statusShow where you are and what's changed. This is what plain grit runs.grit configRead, set, list or remove configuration values.

Making changes

grit addStage changes. With no paths, stages everything.grit commitStage every change and record a new commit.grit diffShow uncommitted changes, or the change a commit introduced.grit restoreRestore working tree and/or index paths from HEAD, the index, or another revision.

History

grit logShow recent commits, newest first, a page at a time.grit shortlogList the commits on this branch that aren't on the target branch yet.grit showShow a commit, tag or branch, and a summary of what it changed.

Branches and tags

grit branchList branches, or create or delete one.grit switchSwitch to another branch, or create one and switch to it.grit mergeMerge another branch into the current one.grit pickCopy a single commit onto the current branch.grit tagList tags, or create or delete one. A new tag points at the current commit.

Remotes

grit remoteList remotes, add one, or list refs on a remote.grit fetchDownload new commits, branches and tags from a remote.grit pullFetch from the remote and bring the current branch up to date.grit pushPublish the current branch, or your tags, to a remote.grit authSign in to GitHub so HTTPS pushes and fetches just work.grit bundleCreate, verify, and list git bundle files for offline transfer.

Maintenance

grit updateUpdate grit to the latest release.grit skillPrint an agent skill that explains how to use grit.grit completionsGenerate shell completion scripts for bash, zsh, and fish.

Plumbing

grit upload-packServe a fetch or clone of a repository over stdin and stdout.grit receive-packAccept a push to a repository over stdin and stdout.grit managerA credential helper that stores passwords and tokens in the Windows Credential Manager.

The library

A fast, linkable Git library for Rust. Everything the CLI does goes through it: open repositories, read objects and refs, diff, revwalk, fetch and push.
