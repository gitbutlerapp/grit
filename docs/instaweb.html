git instaweb

Grit ships a built-in repository browser: no Perl gitweb, no external httpd. From any repository, run: 

git instaweb

This starts grit-instaweb (built alongside grit-git) on 127.0.0.1:1234 by default, then opens your configured browser. Lifecycle commands match upstream Git: 

git instaweb --start --port=4321
git instaweb --stop
git instaweb --restart

Configuration keys: instaweb.port, instaweb.local, instaweb.browser. The library API lives in grit_lib::instaweb; see examples/instaweb.rs.
