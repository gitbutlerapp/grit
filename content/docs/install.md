## Install

```
curl -fsSL https://grit-scm.com/install | sh
```

On Windows, run `irm https://grit-scm.com/install.ps1 | iex` in PowerShell. With a Rust toolchain you can also run `cargo install grit-cli`. Once installed, [`grit update`](../update/) keeps it current.
